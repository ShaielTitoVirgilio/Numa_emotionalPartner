# Dependencias de Numa, con version fija.
#
# Por que estan pineadas: sin version, cada build de Render instalaba lo ultimo
# publicado en ese momento, asi que dos deploys del mismo commit podian levantar
# librerias distintas y produccion terminaba corriendo algo que nadie eligio ni
# podia reproducir en local (paso: produccion tenia supabase 2.31.0 mientras el
# venv local tenia 2.28.3). Estos numeros salen de un `pip freeze` corrido en la
# shell de Render el 2026-09-18, con el servicio andando.
#
# Como actualizar algo: cambiar la version aca, deployar y verificar. La familia
# supabase (supabase, supabase-auth, postgrest, realtime, storage3,
# supabase-functions) se mueve JUNTA: supabase==X exige supabase-auth==X exacto,
# asi que subir una sola rompe el build.
#
# Contrapartida asumida: los parches de seguridad ya no llegan solos en cada
# deploy. Para eso esta Dependabot, que avisa cuando hay algo nuevo.
#
# Python: 3.13.13 en Render (ver .python-version).
